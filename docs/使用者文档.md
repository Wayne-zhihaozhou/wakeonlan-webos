# 使用者文档

面向要安装、部署并使用「Wake on LAN for webOS TV」的用户。按照本文操作，可以让你的 LG 电视每次开机后自动唤醒局域网内的电脑。

> 相关文档：
> - 开发者 / 架构 / 部署细节：[开发者文档](./开发者文档.md)
> - 项目首页：[README](../README.md)

---

## 1. 这个应用能做什么

- 在电视上用一个可视化界面选择/填写目标电脑的 **MAC 地址**、**目标 IP** 和 **端口**。
- **扫描局域网**，自动列出在线电脑（IP + MAC），免手动输入。
- **保存配置**：电视重启后配置不丢。
- **立即唤醒**：手动测试电脑能否被唤醒。
- **开机自动唤醒**：电视每次开机（含从待机快速恢复）都会自动发送一次 Wake-on-LAN 魔术包，把目标电脑唤醒。

---

## 2. 前置条件

你需要准备：

| 项目 | 要求 |
|---|---|
| 电视 | LG webOS 电视，已开启**开发者模式** |
| 电脑 | 与电视同一局域网，且需要被唤醒的电脑已启用 **Wake-on-LAN** |
| 部署用的电脑 | 一台 Windows 电脑，已安装 Node.js 与 ares 命令行工具 |

### 2.1 电视端：开启开发者模式

1. 在电视的 LG Content Store 中搜索并安装 **Developer Mode** 应用。
2. 打开 Developer Mode，确保 **Dev Mode Status = ON**（有些型号还需开启 **Key Server**）。
3. 记录开发者模式界面**左下角显示的 6 位 Passphrase**（区分大小写，这是连接电视的凭证，请保密）。
4. 让 Developer Mode 保持在前台运行，直到部署完成。

### 2.2 电脑端：安装部署工具

```bash
# 需要 Node.js（建议 14 及以上）
npm install -g @webos-tools/cli
```

安装后可执行 `ares -V` 验证。

---

## 3. 部署应用（一键）

在**项目根目录**打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy-wakeonlan.ps1
```

脚本会自动完成以下步骤：

1. 检查 ares 命令行工具是否就绪；
2. 设置 ares 配置文件为 `tv` 模式；
3. 定位与电视同网段的本地网卡并测试电视连通性；
4. 启动一个本地中继（用于绕开公司 VPN 等网络干扰），并让 ares 走中继连电视；
5. 获取电视的 SSH 密钥（会提示输入 2.1 记录的 Passphrase）；
6. 验证连接；
7. 打包应用（会自动把当前代码的 Git 提交哈希注入到 `appinfo.json`）；
8. 安装到电视并自动启动。

> 若电视 IP 不是默认的 `192.168.1.4`，可指定：
> ```powershell
> .\deploy-wakeonlan.ps1 -TvIp <电视IP>
> ```
> 完整参数见 [开发者文档](./开发者文档.md) §8.2。

部署完成后，电视上会自动打开 **Wake on LAN** 应用。

## 4. 在电视上使用应用

全部操作都用**遥控器**完成：方向键移动焦点，**OK 键**确认/选中，**返回键**退出列表或应用。

### 4.1 选择目标电脑

1. 进入应用后，点击 **「扫描设备」**（方向键移动到该按钮，按 OK）。
2. 电视会扫描局域网内在线电脑，扫描完成后下拉列表中会列出它们的 IP 和 MAC。
3. 用方向键选择目标电脑，按 **OK** 确认；字段会自动填入 MAC 地址和目标 IP。
   - 目标电脑若处于关机状态可能扫描不到，可先让它开机扫描一次，或直接手动填写。
   - 列表里也提供「广播唤醒所有设备」选项（对所有设备发送，需要手动填 MAC）。

### 4.2 手动填写（可选）

如果扫描不到，也可以手动填写：

| 字段 | 说明 |
|---|---|
| MAC 地址 | 目标电脑网卡的物理地址，格式 `AA:BB:CC:DD:EE:FF`（必填） |
| 目标 IP | 目标电脑 IP，或使用广播地址 `255.255.255.255` |
| 端口 | 魔术包发送端口，默认 `9` |

> 输入框平时是只读的；聚焦后**先按一次 OK** 才会弹出软键盘，方便遥控器操作。

### 4.3 保存与测试

1. 点 **「保存」**，配置写入电视，重启不丢。
2. 点 **「立即唤醒（测试）」** 验证目标电脑能否被唤醒。
3. 验证成功后，电视每次开机都会自动唤醒这台电脑。

### 4.4 退出应用

点 **「退出」**，或直接按遥控器 **返回键**。

### 4.5 状态自诊断

界面的 **「开机触发状态」** 一栏会实时显示后台服务是否正常，包括：

- 后台服务是否常驻；
- 开机触发是否注册成功；
- 收到多少次开机事件；
- 最近一次魔术包发送结果。

标题栏还会显示当前版本号和 `buildHash`（即电视上运行的是哪一次代码提交），便于反馈问题。

## 5. 常见问题

### 5.1 部署时连不上电视

- 确认电视已开机、Developer Mode 应用在**前台**运行、**Dev Mode Status = ON**。
- 确认电脑与电视在同一局域网。
- 确认电视 IP 正确（用 `-TvIp` 指定）。
- 若电脑装有公司 VPN（如 SecoClient）且与家庭网段冲突，脚本内置的中继已尝试绕开；仍失败可参考 [TROUBLESHOOTING.md](../docs/探索经验/TROUBLESHOOTING.md)。

### 5.2 提示输入 Passphrase

脚本需要电视开发者模式左下角的 6 位口令。也可以提前写入环境变量 `WEBOS_PASSPHRASE`，或放到项目根目录的 `passphrase.txt`（该文件已被 git 忽略，请勿提交）。

### 5.3 点「立即唤醒」后电脑没开机

从这几个方向排查：

- **目标电脑**：确认已在 BIOS 和网卡驱动里启用 **Wake-on-LAN / 网络唤醒**；部分主板需在操作系统（Windows 设备管理器 → 网卡 → 电源管理）中勾选「允许此设备唤醒计算机」。
- **目标电脑已断电**：完全断电（拔电源）后无法用魔术包唤醒。
- **网络**：魔术包默认走 UDP `9` 端口广播；确认电脑与电视同一网段，且防火墙未拦截（可临时放行 UDP 9）。
- **MAC 地址**：确认填的是目标电脑**有线网卡**的 MAC（笔记本合盖走无线时用无线网卡 MAC）。
- **验证魔术包真的发出**：可在电脑上运行 `.\listen-magic-packet.ps1 -Port 9` 监听，若收到 102 字节且 MAC 正确，说明电视端发送正常，问题在目标电脑的 WOL 设置。

### 5.4 电视上显示「后台服务无响应」

- 尝试重新部署一次（脚本会重新安装并启动服务）。
- 确认服务已常驻：用 [电视 SSH 调试指南](../docs/探索经验/电视SSH调试指南.md) 的 SSH 方式查看 `getStatus` 的 `resident.ok` 是否为 true。
- 电视系统升级后 tvpower 相关内部 API 可能变化，需重新部署验证。

### 5.5 改了配置或代码，电视上没变化

- 应用界面显示 `buildHash`，与当前仓库最后一次部署的提交对比，确认电视上跑的是否为新版本。
- 只改文档不重新打包时，`buildHash` 不会变化，属正常现象。

---

## 6. 安全与隐私

- 开发者模式的 **Passphrase 是电视的访问凭证**，请勿外泄或提交到仓库；`passphrase.txt` 已被 git 忽略。
- 部署脚本会临时修改 ares 的电视连接配置，正常情况下结束后会自动还原；若中途被强制中断，请检查 `%APPDATA%\.webos\tv\novacom-devices.json` 的 `host` / `port` 是否已还原为电视实际地址。
