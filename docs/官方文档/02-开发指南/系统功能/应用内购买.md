# 应用内购买（In-App Purchase）
> 原文链接: https://webostv.developer.lge.com/develop/guides/in-app-purchase ｜ 简体中文翻译

若要在你的 VOD 或游戏应用中提供付费产品或内容，则必须使用应用内购买（In-App Purchase）。要完成在你的应用内发起的交易请求，你需要一个计费系统（或服务）。计费系统应具备以下标准：

-   接收并处理在应用内对付费产品或内容发起的购买请求
-   与金融服务机构（例如银行、信用卡公司、移动服务提供商）合作以完成交易
-   保存并跟踪支付历史记录
-   需要最高级别的安全性，以确保支付和数据管理的安全

![应用内购买概览](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1649914915/webOS-TV/images/docs/guides/Overview_of_In-App_Purchase_njffk3.png)

由于要求标准较高，通常建议使用可靠的第三方计费解决方案。第三方计费服务背后的逻辑因解决方案而异；然而，可靠的第三方通常具有以下特征：

-   提供其自有的应用内购买库（library）
-   提供现成的支付用户界面（UI）
-   与全球或本地的各大金融服务机构保持长期合作关系
-   提供安全可靠的服务

用于应用内购买的 LG 计费服务（LG Billing Service）已不再提供。如果你已决定在应用内提供付费内容，我们推荐使用 [Paymentwall](https://www.paymentwall.com/lg-tv) 的解决方案。如果你的应用使用了其他第三方计费解决方案，我们可能会要求你另行签订合同。

## 使用 Paymentwall 的示例

在本节中，你可以通过一些 UI 截图大致了解如何使用 Paymentwall 的解决方案。要使用 Paymentwall 提供的支付解决方案，你首先需要像下面这样将他们的计费库（billing library）添加到你的应用中：

```javascript
<script
  type='text/javascript'
  src='https://api.paymentwall.com/js/pwsmart/ver/pwsmart.1.4.js'
></script>
```

通过设置以下内容来配置支付环境：

-   由 Paymentwall 签发的应用标识密钥（Key）
-   国家代码（Country code）
-   用于显示支付 UI 的目标元素
-   语言（Language）
-   智能电视品牌（Brand of smart TV）

```javascript
PWSmartGateway.init({
  key: 'YOUR_PROJECT_KEY',
  countryCode: 'US',
  containerId: 'my-div',
  lang: 'en',
  gaWebPropertyId: 'UA-XXXX-Y',
  brand: 'lgtv',
});
```

当用户在你的应用内请求购买某个商品时，你需要调用在你的应用中显示支付表单的函数。所购商品的信息、成功回调（success callback）函数和失败回调（failure callback）函数是必需的参数。

```javascript
PWSmartGateway.showPaymentForm(
  {
    productId: 'Order_2045',
    productName: '5000 Gold Coins',
    currency: 'USD',
    amount: '9.99',
    userId: 'test_user_2',
    onExit: function () {},
    showBackButton: true,
    enablePaymentRecoverFlow: true,
    titles: {
      buyHeading: 'Subscribe to #product',
      buyHeadingRecurring: '#price per #period',
    },
  },
  function () {
    alert('Payment Success'); // 成功时的回调
  },
  function (error) {
    alert('Payment Failure'); // 失败时的回调
  }
);
```

如果该函数被成功调用，支付 UI 就会显示在目标元素中。
