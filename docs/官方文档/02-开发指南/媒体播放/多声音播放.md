# 多声音播放（Multi-Sound Playback）
> 原文链接: https://webostv.developer.lge.com/develop/guides/multi-sound-playback ｜ 简体中文翻译

如果你要实现一个播放多种声音（即背景音乐和音效）的应用，你需要仔细阅读以下指南和示例代码。

> **重要（Important）**
>
> 在本文中，我们同时介绍了用于播放多种声音的 audio 元素（audio element）和 Web Audio API。然而，由于存在种种限制，我们强烈建议你使用 audio 元素来播放背景音乐。

## 使用音频元素（Using audio element）

你的应用中应该只使用一个 audio 元素。由于 audio 标签在 webOS TV 上使用硬件解码器，应用在切换时有时会发生媒体资源冲突。为防止 webOS TV 上的媒体资源冲突，你的应用中应该只使用一个 audio 元素。如果你的应用中声明了一个或多个 audio 元素，声音将无法同时播放。

> **注意（Note）**
>
> - 音频内容的时长必须至少为 1 秒。
> - 在应用挂起（suspend）时，你应该暂停声音，并在应用进入前台时恢复播放。请参阅[示例代码](https://github.com/webOS-TV-app-samples/MultiSound)。
> - 在 webOS TV 模拟器（Emulator）上，多声音播放可以配合多个 audio 元素工作，这与真实设备上的表现不同。

### 音频元素的使用场景（Use case for audio element）

在你的应用中播放**背景音乐**。

### 支持的 MIME 类型（Supported MIME types）

audio 元素支持以下 MIME 类型：

- audio/aac
- audio/mp4
- audio/x-m4a
- audio/mpeg
- audio/x-mpeg
- audio/x-mp3
- audio/mp3

以下示例演示了如何使用 audio 元素播放 mp3 格式的文件：

```html
<audio controls autoplay>
  <source type="audio/mp3" src="http://media.w3.org/2010/05/sound/sound_300.mp3"/>
</audio>
```

## 使用 Web Audio API（Using Web Audio API）

Web Audio API 是一种用于在 Web 应用中处理和合成音频的高级 JavaScript API。

供你参考，以下为 Web Audio API 的规范与参考文档。

- [W3C Web Audio API](http://www.w3.org/TR/webaudio/)
- [MDN Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)

> **注意（Note）**
>
> webOS TV 上不支持 createMediaElementSource() 方法。

由于一个应用中只能使用一个 audio 元素，因此你应该使用 Web Audio API 来播放音效。

使用 Web Audio API 播放声音时，在 webOS TV 上存在约 500 毫秒的延迟问题，因此在使用 Web Audio API 之前你应该注意到这一点。当你使用的音效时长超过 1 秒时，你必须在应用挂起（suspend）时停止该声音，因为平台不会在应用挂起时自动停止 Web Audio API 的声音。请参阅[示例代码](https://github.com/webOS-TV-app-samples/MultiSound)。

### Web Audio API 的使用场景（Use case for Web Audio API）

在你的应用中播放**音效**。

### 支持的媒体格式（Supported media formats）

请参阅[支持的媒体与 DRM 格式](https://webostv.developer.lge.com/develop/specifications/streaming-protocol-drm)。

## 其他声音格式（Other sound formats）

你不能在 webOS TV 上使用 SoundFont。SoundFont 是一种用于计算机音乐创作的文件格式及相关技术，其中通常包含多种声音。
