# 动作传感器概述
> 原文链接: https://webostv.developer.lge.com/develop/guides/motion-sensor-overview ｜ 简体中文翻译

webOS TV 动作传感器 API（Motion Sensor API）提供光标输出和不同类型的动作数据。此前的魔法遥控器 API（Magic Remote API）仅部分支持动作传感器功能，而新的、升级后的动作传感器 API 在实现相关功能时提供了更好的易用性。此外，传感器参数的覆盖范围也得到了扩展（例如：参数、未校准传感器数据、重力、动作检测器等），并且最多可以处理二十个客户端。

关于动作传感器 API 的详细信息，请参阅 [Magic Remote API 参考](https://webostv.developer.lge.com/develop/references/magic-remote)。

以下是支持的传感器类型：

```javascript
TYPE_COORDINATE
TYPE_ACCELEROMETER
TYPE_ACCELEROMETER_UNCALIBRATED
TYPE_GRAVITY
TYPE_GYROSCOPE
TYPE_GYROSCOPE_UNCALIBRATED
TYPE_LINEAR_ACCELERATION
TYPE_GAME_ROTATION_VECTOR
TYPE_SIGNIFICANT_MOTION
TYPE_STEP_COUNTER
TYPE_STEP_DETECTOR
```

> **注意**
>
> 动作传感器（Motion Sensor）支持 webOS TV 24 或更高版本。

## 使用场景

使用 webOS TV 动作传感器 API 可以实现各种游戏应用。

### 高尔夫（Golf）

当玩家挥动高尔夫球杆时，击球的力量与加速度和方向有关，同时与球杆的朝向（orientation）也有关。球杆的长度以及它所朝向的方向也需要纳入考虑，以便计算出球杆杆头上的精确击球点。这些与游戏旋转向量（game rotation vector）四元数（quaternion）中用于比例（scale）和矢量（vector）的分量相对应。

### 竞速（Racing）

![动作传感器竞速场景图](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1708327357/webOS-TV/images/docs/guides/Motion_sensor_Racing_resized_xjxqag.jpg)

需要操控或驾驶车辆或物体的游戏（例如马里奥赛车或水上摩托）可以利用控制器的倾斜（tilt）来确定运动方向。倾斜可以通过校准后的加速度计输出计算得出。

> **注意**
>
> webOS TV 动作传感器 API 提供了 HexGL 游戏应用的使用示例。要了解更多信息，请查看 [HexGL 示例应用](https://github.com/webOS-TV-app-samples/HexGL)。

### 网球（Tennis）

网球游戏使用与高尔夫游戏相似的原理。击球的力量与加速度和方向有关，同时与球拍的朝向也有关。在更复杂的网球游戏中，游戏引擎还需要将这些信息转化为数字球拍，以确定球拍的哪个部分击中了球，并计算其旋转。这些与游戏旋转向量四元数中用于比例和矢量的分量相对应。

### 保龄球（Bowling）

![动作传感器保龄球场景图](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1708327856/webOS-TV/images/docs/guides/Motion_sensor_Bowling_resized_zwpma8.jpg)

简单的保龄球游戏可以使用与高尔夫和网球游戏相同的原理。例如，如果用户按住按钮来摆动球，然后松开按钮将球掷出，那么在松开的这个时刻，游戏旋转向量可以确定球的轨迹。此外，通过保留一小段动作的历史记录，游戏引擎可以为球的运动添加旋转。

### 健身与舞蹈（Fitness and Dance）

![动作传感器健身与舞蹈场景图](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1708327855/webOS-TV/images/docs/guides/Motion_sensor_Fitness_and_Dance_resized_gibvmj.jpg)

健身游戏会引导用户以与屏幕上所示内容相匹配的特定方式运动。对于某首歌曲或某个健身动作，游戏拥有一组预期的动作库；在缺乏摄像头的情况下，很难确定用户确切的肢体动作。然而，当用户尝试与屏幕上所看到的内容相匹配地运动时，动作传感器会输出矢量（vector）和比例（scale）信息，并检查用户的运动与动作库中定义的动件的匹配程度。由于这类游戏节奏快且要求精确，因此只需在每次动作结束时获取朝向数据即可。除了浏览菜单选项之外，这里不需要任何按钮。通过查看不同方向（向上、向下和侧向）的加速度，有助于确定用户坐标系加速度（user-frame acceleration），从而使系统更加健壮。对这一用户坐标系加速度进行积分可以得到用户坐标系速度（user-frame velocity），它也可以用来验证健身/舞蹈动作；不过，由于可能存在积分误差，建议仅用于较短的时间段。
