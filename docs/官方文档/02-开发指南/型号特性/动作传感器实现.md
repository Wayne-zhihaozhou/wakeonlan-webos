# 动作传感器（Motion Sensor）的实现
> 原文链接: https://webostv.developer.lge.com/develop/guides/motion-sensor-implementation ｜ 简体中文翻译

以下介绍如何在你的应用中（app）使用动作传感器 API（Motion Sensor API）。

## 验证此 API 是否受支持

首先，检查当前 webOS TV 平台上是否存在动作传感器 API（Motion Sensor API）。为此，请调用 `**getSensorState**` 方法并检查其响应。

```javascript
var handle = webOS.service.request("luna://com.webos.service.mrcu", {
  method: "sensor2/getSensorState",
  parameters: {},
  onSuccess: function (inResponse) {
    console.log("Result: " + JSON.stringify(inResponse));
    if (inResponse.isAlive === true) {
      return;
    }
  },
  //If isAlive is false, the motion sensor is in a sleep state. Wake up the
  // Magic Remote to make the motion sensor operational.     },
  onFailure: function (inError) {
    console.log("[" + inError.errorCode + "]: " + inError.errorText);
    // If the errorCode is -1, the current webOS TV version may not support the
    // Motion Sensor API. (For the cause of the error, check errorText).
    // In that case, because the upgraded API is not supported, you can use the
    // previous API
    //(https://webostv.developer.lge.com/develop/references/magic-remote#).
  },
});
```

- 如果 `**returnValue**` 为 true，则可以使用动作传感器 API（Motion Sensor API）。请检查 `**isAlive**` 的值，它用于指示动作传感器当前是否可操作。如果 `**isAlive**` 的值为 true，则动作传感器可操作。如果为 false，则动作传感器处于睡眠状态，因此你需要唤醒魔法遥控器（Magic Remote）。由于魔法遥控器使用电池供电，为了节能，当遥控器在一段时间内未被使用时，传感器便会转入睡眠状态。

- 如果 `**returnValue**` 为 false 且 `**errorCode**` 为 -1，则你正在使用的平台版本很可能不支持动作传感器 API。要查明错误的成因，请检查 `**errorText**`。

## 检查动作传感器事件响应间隔

在确认魔法遥控器的动作传感器处于可操作状态后，请按照以下示例，使用 `**getSensorInterval**` 方法检查动作传感器事件响应间隔。

```javascript
var handle = webOS.service.request("luna://com.webos.service.mrcu", {
  method: "sensor2/getSensorInterval",
  parameters: {},
  onSuccess: function (inResponse) {
    console.log("Result: " + JSON.stringify(inResponse));
  },
  onFailure: function (inError) {
    console.log("Failed to get sensor interval");
  },
});
```

`**minInterval**` 和 `**maxInterval**` 分别表示可配置的事件响应间隔的最小值和最大值，单位为毫秒（msec）。如果间隔超出此范围，`**errorText**` 会提示这是一个错误的间隔。`**interval**` 是当前已设置的事件响应间隔，可以在允许的范围内将其设置为所需的间隔。

## 设置动作传感器事件响应间隔

通过调用 `**setSensorInterval**` 方法，在允许的范围内（10 ≤ `**interval**` ≤ 1000）设置事件响应间隔。单位为毫秒（msec）。

```javascript
var handle = webOS.service.request("luna://com.webos.service.mrcu", {
  method: "sensor2/setSensorInterval",
  parameters: { interval: 10 },
  onSuccess: function (inResponse) {
    console.log("Result: " + JSON.stringify(inResponse));
  },
  onFailure: function (inError) {
    console.log("[" + inError.errorCode + "]: " + inError.errorText);
    // If errorCode is 1006 and errorText is "Wrong Callback Interval", it means a
    // wrong interval error. interval is the currently-set event response interval
    // and can be set to a desired interval within the allowed range.
  },
});
```

## 获取动作传感器事件数据

要获取动作传感器事件数据，请调用 `**getSensorEventData**` 方法。

在调用 `**getSensorEventData**` 方法时，如果必要，你可以通过在 `**sensorType**` 中添加所需数据的名称（以分隔符分隔），从各种数据中选择接收特定种类的数据。

将 `**subscribe**` 设置为 true，即可按设定的间隔周期性地接收事件数据；设置为 false，则只接收一次。

如果 `**subscribe**` 已经是 true（即该方法已被订阅），则无法再发起重复的订阅请求，因此在这种情况下，`**errorText**` 会提示该方法已被订阅。如果不再需要事件数据，则需要取消订阅。

`**getSensorEventData**` 方法可以处理来自多个客户端（client）的请求。它可以同时处理多个客户端请求的 `**interval**` 和不同的 `**sensorType**`。但是，最多只能处理二十个客户端的请求，如果超过此数量，将返回一个错误响应，且 `**errorText**` 会提示请求数量超过了可处理的最大数量。在这种情况下，需要取消不必要的订阅。

```javascript
var subscriptionHandle = webOS.service.request(
  "luna://com.webos.service.mrcu",
  {
    method: "sensor2/getSensorEventData",
    parameters: { sensorType: "all", subscribe: true },
    onSuccess: function (inResponse) {
      if (typeof inResponse.subscribed !== "undefined") {
        if (!inResponse.subscribed) {
          console.log("Failed to subscribe");
        }
      }
      console.log("Result: " + JSON.stringify(inResponse));
      // To-Do something
      return;
    },
    onFailure: function (inError) {
      console.log("[" + inError.errorCode + "]: " + inError.errorText);
      // If errorCode is 1004 and errorText is "Already add subscription", it means
      // that the method has been already subscribed. If motion sensor event data is
      // no longer necessary, cancel the subscription.
      // If errorCode is 1005 and errorText is "Over subscription app/service
      // number", it means the number of processable request is used up. Cancel
      // unnecessary subscriptions to make room for processing of requests.
    },
  }
);

// If you need to unsubscribe the data, use cancel() method as below.
subscriptionHandle.cancel();
```

## 重新初始化旋转中心（center of rotation）

当用户旋转魔法遥控器时，魔法遥控器的旋转中心有时会丢失，从而难以识别魔法遥控器的旋转。此时，通过调用 `**resetQuaternion**`，可以重新初始化旋转中心。请参考[动作传感器示例应用（Motion Sensor sample app）](https://github.com/webOS-TV-app-samples/MrcuSensor)，并检查游戏旋转向量（game rotation vector）。

```javascript
var handle = webOS.service.request("luna://com.webos.service.mrcu", {
  method: "sensor2/resetQuaternion",
  parameters: {},
  onSuccess: function (inResponse) {
    console.log("Result: " + JSON.stringify(inResponse));
  },
  onFailure: function (inError) {
    console.log("Failed to get sensor interval");
  },
});
```

## 取消订阅

要取消订阅，请调用 `**cancelSensorDataSubscribe**` 方法。取消之后，即使旋转魔法遥控器，也不会再传输任何事件数据。

```javascript
var handle = webOS.service.request("luna://com.webos.service.mrcu", {
  method: "sensor2/cancelSensorDataSubscribe",
  parameters: {},
  onSuccess: function (inResponse) {
    console.log("Result: " + JSON.stringify(inResponse));
    return;
  },
  onFailure: function (inError) {
    console.log("[" + inError.errorCode + "]: " + inError.errorText);
    // If errorCode is 1003 and errorText is "Magic remote is not ready", it means
    // the Magic Remote’s motion sensor is not operable. Make it ready and try
    // again.
  },
});
```
