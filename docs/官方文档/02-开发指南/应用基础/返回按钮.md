# 返回按钮
> 原文链接: https://webostv.developer.lge.com/develop/guides/back-button ｜ 简体中文翻译

Magic Remote（魔法遥控器）上的返回（Back）按钮可帮助用户在您的应用中轻松地返回上一级。当用户按下 Magic Remote 上的返回按钮时，您的应用应执行以下操作之一。

-   如果存在上一页面，则返回上一页面。

-   如果当前页面是您应用的入口页面，则
    -   在 webOS TV 6.0 或更高版本上，显示一个询问是否退出应用的弹出窗口。
    -   在 webOS TV 5.0 或更低版本上，启动 Home（主屏幕）启动器。

在您的应用中，您可以组合使用以下选项来处理返回按钮的按下。

## 使用 History API

默认情况下，webOS TV 平台本身会使用 DOM 的 [history 对象](https://developer.mozilla.org/en-US/docs/Web/Guide/API/DOM/Manipulating_the_browser_history)来处理 Magic Remote 上的返回按钮按下。因此，如果您想自定义向后和向前导航的行为，请使用 DOM 的 history 对象。

要使您的应用移动到另一个页面或状态，请使用 [history.pushState()](https://developer.mozilla.org/en-US/docs/Web/API/History/pushState) 将当前的 `**state**` 添加到 `**history**` 栈中。

```javascript
history.pushState(stateData, title, targetURL);
```

只要 `**history**` 栈中存在内容，当用户按下返回按钮时，您的应用就会接收到 `**popstate**` 事件。您的应用可以使用 History API 订阅 `**popstate**` 事件，或者像下面所示那样添加一个事件监听器。

```javascript
window.addEventListener('popstate', function (inEvent) {
  // 接收到返回，如果您需要 history push 中的数据，请检查 inEvent.state
});
```

在 webOS TV 中，当用户在您应用的入口页面按下返回按钮时，屏幕控制权会被移交给 Home（主屏幕）界面。下图展示了 `**history**` 对象如何工作，以及何时应显示 Home（主屏幕）界面。

![返回按钮操作结构（Back Button Operation Structure）](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1649914916/webOS-TV/images/docs/guides/Back_Button_Operation_Structure_t9f1qf.png)

要跟踪应用的状态，请使用 `**popstate**` 事件和 `**pushState()**` 方法。这将允许用户在应用内进行向后导航。请查看 [Back Button Control（返回按钮控制）](https://github.com/webOS-TV-app-samples/BackButtonControl)示例应用，了解如何处理返回按钮的按下。

## 处理返回按钮事件

您可以通过接收返回按钮事件来让您的应用处理返回按钮的按下。该选项在您的应用由单页面组成时尤其有用，因为否则的话，跟踪此类应用的历史可能会非常麻烦。

以下是在您的应用中处理返回按钮按下的方法。

1.  在 _appinfo.json_ 文件中将 **`disableBackHistoryAPI`** 属性设置为 _true_。

    ```javascript
    {
        ...
        disableBackHistoryAPI: true;
        ...
    }
    ```

2.  在您的事件监听器中添加返回按钮的按键码（ **`0x1CD`**，即十进制 **`461`**）。

    ```javascript
    window.addEventListener("keydown", function(inEvent){
        if(window.event) {
            keycode = inEvent.keyCode;
        } else if(e.which) {
            keycode = inEvent.which;
        }
        switch (keycode) {
            case 461: doBack(); break;
            case 38: doUp(); break;
            case 40: doDown(); break;
            ...
        }
    });
    ```

> **注意（Note）**
>
> 有关 Magic Remote（魔法遥控器）及其各按钮按键码的更多信息，请参阅 [Magic Remote](https://webostv.developer.lge.com/develop/guides/magic-remote)。

## 实现返回按钮功能以退出应用

如果您的应用手动处理返回按钮的按下（例如，当您将 **`disableBackHistoryAPI`** 属性设置为 _true_ 时），则可能需要返回按钮功能来强制退出应用或启动 Home（主屏幕）启动器。

当执行 webOSTV.js 库中的 **`webOS.platformBack()`** 方法时，在 webOS TV 6.0 或更高版本上会显示一个询问是否退出应用的弹出窗口，或者在 webOS TV 5.0 或更低版本上会启动 Home（主屏幕）启动器。如果您想要一个自定义的退出弹出窗口，请不要使用 **`webOS.platformBack()`** 方法，而是自行实现一个自定义的退出弹出窗口，并使用 **`window.close()`** 方法来退出应用。

以下代码是在返回按钮事件监听器中使用 [webOS.platformBack()](../../03-API参考/webOSTV.js库/webOSTV.js的webOSAPI.md#platformback) 方法的示例。

```javascript
<script type="text/javascript" src="webOSTVjs-1.1.0/webOSTV.js"></script>
...
<script>
...
function doBack() {
    // 为返回按钮执行某些操作();

    // 如果需要打开 Home（主屏幕）UI
    if (someCondition == true)
        webOS.platformBack();
}
...
</script>
```
