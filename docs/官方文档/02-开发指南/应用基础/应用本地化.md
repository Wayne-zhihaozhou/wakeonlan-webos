# 应用本地化
> 原文链接: https://webostv.developer.lge.com/develop/guides/app-localization ｜ 简体中文翻译

要将你的应用本地化为一种以上语言，你需要为每种语言编写额外的 _appinfo.json_ 文件。由于顶层 _appinfo.json_ 文件中的应用 ID（app ID）和版本号（version）会被用于校验和修正各文件的值与结构，请确保每个本地化 _appinfo.json_ 文件中的应用 ID 和版本号与顶层 _appinfo.json_ 文件中的保持一致。任何未通过校验的应用都无法被打包或上传。

根据区域设置（locale settings）的不同，启动器（launcher）和主屏幕（Home screen）上会显示与之匹配的应用信息。

要在特定区域设置下添加应用信息，你首先需要在 resources 文件夹下创建一个 locale 文件夹，然后在正确的位置写入一个 _appinfo.json_ 文件，如下所示：

![appinfo.json 本地化文件的位置结构](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1649919096/webOS-TV/images/docs/guides/2091_pbqsel.png)

> **注意（Note）**
>
> locale 由语言（Language）、文字（Script）以及国家/地区（Country/Region）信息组成。（例如：ko-KR、mn-Cy-MN）

借助额外的 _appinfo.json_ 文件，你的应用可以用不同语言显示其标题和描述。其余所有属性均与顶层 _appinfo.json_ 文件保持一致。

```shell
{
  "title": "Translated app title",
  "appDescription": "Translated app description"
}
```

> **重要（Important）**
>
> - 在用于本地化的 _appinfo.json_ 文件中，你应该填写 appDescription 和 title 属性。
>
> - 如果你在 _appinfo.json_ 文件中使用了非拉丁字符（非 ASCII 字符），你应该以不带 BOM 的 UTF-8 格式保存该文件。

当添加了与 locale 信息相对应的 _appinfo.json_ 文件之后，若 locale 的值发生变化，webOS TV 会先将顶层 _appinfo.json_ 文件加载到系统内存中，然后再根据 locale 设置覆盖其他 _appinfo.json_ 文件。
