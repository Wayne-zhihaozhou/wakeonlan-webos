# 支持的应用分辨率
> 原文链接: https://webostv.developer.lge.com/develop/specifications/app-resolution ｜ 简体中文翻译

下表列出了图形与视频所支持的应用分辨率。

|  | Full HD 机型 (FHD) | Ultra HD 机型 (UHD) |
| --- | --- | --- |
| 图形显示分辨率 | 1280 x 720 HD (2K) | 1920 x 1080 FHD (2K) |
| 视频播放分辨率 | 1920 x 1080 FHD (2K) | 3840 x 2160 UHD (4K) |

若要在 Ultra HD 机型上获得高质量的图形显示分辨率，应将应用的分辨率设置为 1920x1080。但是，Full HD 机型支持的图形显示分辨率最高为 1280x720。因此，为了同时针对 Ultra HD 机型和 Full HD 机型优化显示分辨率，我们建议您向 [LG Seller Lounge](https://seller.lgappstv.com/) 提交两个图形分辨率分别为 1920x1080 和 1280x720 的软件包。

图形显示分辨率的默认设置为 1920x1080。若要将分辨率更改为 1280x720，您应在 *[appinfo.json](../../03-API参考/配置文件/appinfo.json应用元数据.md)* 文件中将 [`resolution`](../../03-API参考/配置文件/appinfo.json应用元数据.md#resolution) 属性设置为 1280x720。

注意

若要获取 Web 应用的应用分辨率（用于图形显示），请使用

`window.innerWidth`

和

`window.innerHeight`

属性。或者，若要查看视频播放分辨率，请使用 webOSTV.js 库中 webOS API 的

[`deviceInfo`](../../03-API参考/webOSTV.js库/webOSTV.js的webOSAPI.md#deviceinfo)

的

`screenWidth`

和

`screenHeight`

属性。
