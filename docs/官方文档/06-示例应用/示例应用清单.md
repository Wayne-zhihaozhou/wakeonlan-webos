# 示例应用（Samples）
> 原文链接: https://webostv.developer.lge.com/develop/samples ｜ 简体中文翻译

请查看 GitHub 上的示例应用，它们将帮助加速您的应用开发。

### [无障碍](https://github.com/webOS-TV-app-samples/Accessibility)

此示例应用展示如何获取无障碍设置的值。

### [应用生命周期](https://github.com/webOS-TV-app-samples/AppLifecycle)

此示例应用展示应用的状态如何随每个与启动相关的事件而变化。

### [返回按钮控制](https://github.com/webOS-TV-app-samples/BackButtonControl)

此示例应用演示应用画面如何随 Magic Remote 遥控器的返回按钮而变化。您可以通过 appinfo.json 的 disableBackHistoryAPI 值来查看其中的差异。

### [数据库 (DB8)](https://github.com/webOS-TV-app-samples/DB8)

此示例应用展示如何使用 putKind() 方法创建一个 kind，即一种可被视为表的对象。

### [Hello World 服务](https://github.com/webOS-TV-app-samples/HelloWorldService)

此示例应用演示如何创建 webOS TV 服务、从 Web 应用调用该服务并显示响应。

### [托管 Web 应用](https://github.com/webOS-TV-app-samples/HostedWebApp)

此示例应用使用 JavaScript 和 HTML5 meta 标签实现对 Google 搜索网站的 URL 重定向。

### [HexGL](https://github.com/webOS-TV-app-samples/HexGL)

这是 Thibaut Despoulain 开发的未来派 HTML5 赛车游戏 HexGL 的源代码。

### [Luna 服务](https://github.com/webOS-TV-app-samples/LunaService)

此示例应用展示如何使用 webOSTV.js 库调用 luna 服务 API。

### [媒体播放](https://github.com/webOS-TV-app-samples/MediaPlayback)

此示例应用演示如何在 Web 应用中实现媒体播放。

### [MRCU 传感器](https://github.com/webOS-TV-app-samples/MrcuSensor)

此示例应用演示如何调用 Motion Sensor API 并检查传感器数据。

### [多路声音](https://github.com/webOS-TV-app-samples/MultiSound)

此示例应用演示如何使用 Web Audio API 和 audio 元素在应用中播放多路声音。

### [竖屏模式](https://github.com/webOS-TV-app-samples/PortraitMode)

此示例应用演示如何在应用中支持竖屏模式。

### [遥控器](https://github.com/webOS-TV-app-samples/RemoteControl)

此示例应用展示如何使用 LG Magic Remote 处理用户输入。它还展示从外部输入设备接收到的按键码。

### [分辨率](https://github.com/webOS-TV-app-samples/Resolution)

此示例应用演示如何使用 webOSTV.js 库获取应用中的视频分辨率和 UI 分辨率。

### [虚拟键盘](https://github.com/webOS-TV-app-samples/VirtualKeyboard)

此示例应用实现虚拟键盘的使用，虚拟键盘是 webOS TV 应用的主要文本输入方式。

### [Web 存储](https://github.com/webOS-TV-app-samples/WebStorage)

此示例应用实现两种不同的 Web 存储方式：本地存储和会话存储。

### [webOSTV.js 库](https://github.com/webOS-TV-app-samples/webOSTVJSLibrary)

此示例应用展示如何使用 webOSTV.js 库。
