# 资源监视器开发者指南
> 原文链接: https://webostv.developer.lge.com/develop/tools/resource-monitor-dev-guide ｜ 简体中文翻译

本指南将说明如何使用资源监视器监视资源占用。

## 准备工作

在开始监视之前，你需要使用 webOS CLI 或 webOS Studio 设置好你的设备和 PC。

### 打开设备的开发者模式

要测量设备上的资源占用，必须打开设备的开发者模式。有关如何打开，请参见[打开开发者模式](../../01-快速入门/开发者模式应用.md#turning-developer-mode-on)。

### 注册并连接设备

设备应注册到安装了资源监视器的 PC 并与之连接。有关如何连接，请参见[连接 TV 与 PC](../../01-快速入门/开发者模式应用.md#connecting-tv-and-pc)。

### 以开发者模式安装应用

要测量应用的资源占用，应以开发者模式安装该应用。有关如何安装，请参见 [webOS CLI 开发者指南 | 将 Web 应用部署到 TV 设备](../命令行工具/webOSCLI开发者指南.md#deploy-the-web-app-on-a-tv-device) 或 [webOS Studio 开发者指南 | 打包、安装并启动应用](../webOS%20Studio/webOSStudio开发者指南.md#package-install-and-launch-the-app)。

## 选择设备和应用

首先，选择要测量其资源占用的设备和应用。

![webOS 资源监视器主页](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_700/v1727153397/webOS-TV/images/docs/tools/resource_monitor_introduction_home_k7hehy.webp)

### 选择设备

1. 点击 **Select Device** 框。随后会显示设备列表。

![在资源监视器中选择设备](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_700/v1727155717/webOS-TV/images/docs/tools/resource_monitor_dev_guide_select_device_wlrzzd.webp)

1. 选择目标设备并点击 **Select**。
2. 在设备上批准连接请求。

注意

- 如果你看不到该设备，请先注册设备。请参见[注册并连接设备](#register-and-connect-the-device)。
- 如果你的设备在列表中，但设备上没有出现连接请求，请检查以下各项：
  - 在 PC 中注册的设备是否可通过网络访问
  - 设备的开发者模式是否已打开

### 选择应用

1. 点击 **Select App** 框。随后会显示以开发者模式安装的应用列表。
2. 选择目标应用并点击 **Select**。
3. 点击 **Continue** 以打开仪表板。

注意

- 如果应用不在列表中，请检查目标应用是否以开发者模式安装。列表中仅显示以开发者模式安装的应用。

### 更改目标设备或应用

要更改目标设备或应用，

- 点击顶部的徽标，或者
- 点击屏幕右上方设备信息面板中显示的设备名称。

## 仪表板

你可以实时监视目标设备的资源占用。

![webOS 资源监视器仪表板](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_700/v1727153397/webOS-TV/images/docs/tools/resource_monitor_introduction_dashboard_aazf65.webp)

### 开始和结束测量

- 要开始测量，请点击顶部标题栏上的开始按钮。
- 要结束测量，请点击顶部标题栏上的停止按钮。

系统会询问你是否保存测量数据。要保存数据，请点击 **Save**。

### 实时监视系统资源占用

屏幕顶部区域的四个仪表图表会实时显示整个系统的资源占用。

- CPU
- Memory (RSS + Swap + GPU)
- Storage
- Network

### 资源数据图表

到目前为止所测量的资源占用数据会以图表形式显示。

- 关键资源数据可在单个视图中查看。
- 可以比较系统与应用的占用情况。

## 数据分析

你可以精确地分析所测量的资源占用数据。

![webOS 资源监视器详细数据分析](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_700/v1727153397/webOS-TV/images/docs/tools/resource_monitor_introduction_detailed_analysis_fevj9l.webp)

### 数据比较

各图表对齐到同一时间轴，因此你可以比较某一时间点的资源占用数据。

- 通过垂直对齐的图表，你可以发现某段时间内的资源占用趋势。
- 如果将鼠标光标停留在某个资源图表上，其他图表会同步到同一时间点，并显示该时间点的数据。

### 附加信息

系统提供有用的统计数据，例如最大值、最小值和平均值，因此你可以判断资源占用是否存在异常。

### 选择时间范围

你可以选择特定的时间范围进行深入分析。

- 通过调整顶部的时间轴，你可以更改用于分析的时间范围的起点和终点。
- 时间轴的调整会立即应用到所有图表。

![webOS 资源监视器时间范围选择](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_700/v1727155717/webOS-TV/images/docs/tools/resource_monitor_dev_guide_time_scope_selection_vigap4.webp)

## 历史记录

所测量的资源数据可以保存、加载、导出或导入。

![webOS 资源监视器历史记录](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_600/v1727155717/webOS-TV/images/docs/tools/resource_monitor_dev_guide_history_gsnsio.webp)

### 保存和加载

测量结束后，你可以保存数据。你也可以随时在 History 中加载已保存的数据。

### 导出和导入

你可以将 History 中保存的数据下载为文件，并在需要时与他人共享该文件。共享的文件可以在他人 PC 上安装的资源监视器工具中加载。

## 设置

### 浅色/深色模式

你可以选择浅色模式或深色模式主题。

![webOS 资源监视器深色模式](https://res.cloudinary.com/dcsdn4mzr/image/upload/c_scale,w_900/v1727155716/webOS-TV/images/docs/tools/resource_monitor_dev_guide_dark_mode_izdfvl.webp)

### 默认间隔

你可以设置测量资源占用的默认时间间隔。

### 自动开始监视

如果此选项已打开，则一旦你选择设备及应用，资源占用监视就会自动开始，无需点击开始按钮。
