# Beanviser 安装
> 原文链接: https://webostv.developer.lge.com/develop/tools/beanviser-installation ｜ 简体中文翻译

Beanviser 并未打包在 webOS TV SDK 中。你可以从本页面下载 Beanviser。使用 Beanviser 之前，请先确认系统要求。

## 系统要求

请查看使用 Beanviser 所需的软件和硬件要求。

### 软件要求

| 操作系统 | 要求 |
| --- | --- |
| Linux | Ubuntu 10.04 至 18.04。（仅限 64 位）<br>目前在 Ubuntu 20.04 或更高版本上不可用 |
| macOS | macOS X 10.11 或更高版本（仅限 64 位） |
| Windows | Windows 7 或更高版本（仅限 64 位） |

### 硬件要求

| 硬件组件 | 要求 |
| --- | --- |
| CPU | 1 GHz 或更快 |
| 内存 | 1 GB 或以上 RAM |
| 显卡 | 1024 x 768 或更大 |
