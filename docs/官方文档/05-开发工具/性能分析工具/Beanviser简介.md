# Beanviser 简介
> 原文链接: https://webostv.developer.lge.com/develop/tools/beanviser-introduction ｜ 简体中文翻译

Beanviser 是一款图形化工具，用于测量在真实 webOS TV 或模拟器上运行的应用或服务的性能。

## 为什么要使用 Beanviser？

我们建议你在将应用正式部署用于商业用途之前，使用 Beanviser 对其进行评估。Beanviser 让你能够查看 CPU 和内存消耗指标、检查应用的稳定性、检查内存泄漏等。

最好让 Beanviser 对应用进行数天的评估，以便真实地了解应用的运行状况。

注意

Beanviser 从 v1.5 起新增了 UDC（Usage Data Collection，使用数据收集）功能。该功能会收集 Beanviser 使用方式的相关信息，这些数据用于提升 SDK 质量。它不会收集任何可用于唯一识别你个人身份的信息。你可以在 [Community](https://forum.webostv.developer.lge.com) 或通过 [developer@lge.com](mailto:developer@lge.com) 向我们提出关闭该功能的请求。

## Beanviser 的主要功能

### 检查系统级 CPU 使用率

为以下类别提供图形化视图：

- 总体使用率
- 用户模式使用率
- 内核模式使用率
- 其他使用率

### 检查进程级 CPU 使用率

为以下类别提供图形化视图：

- JS 服务
- 原生服务
- 你安装的应用
- 系统进程（不属于其他分组的进程）。

注意

webOS TV 1.x 和 2.x 不支持此功能。

### 检查系统级内存使用情况

为以下类别提供图形化视图：

- 系统内存
- 内存缓冲区
- 交换内存

### 检查进程级内存使用情况

为以下类别提供图形化视图：

- JS 服务
- 原生服务
- 你安装的应用
- 系统进程（不属于其他分组的进程）。

注意

webOS TV 1.x 和 2.x 不支持此功能。

### 获取媒体信息

提供目标设备上播放的媒体详情。这些详情包括：

- 媒体元数据
- 媒体缓冲区图表
- 媒体比特率图表

注意

此功能从 Beanviser v1.5 起可用。

### 获取网络信息

提供目标设备上所用网络的详情。这些详情包括：

- 关于已发送和已接收数据包的详情。
- TCP/UDP 套接字数量及其套接字描述符信息。

注意

此功能从 Beanviser v1.5 起可用。

### 比较日志文件

允许你比较在不同时间采集的日志文件。

- 日志必须是同一类型。
- 例如，你可以将系统 CPU 日志与系统 CPU 日志比较，但不能将系统 CPU 日志与系统内存日志比较。
- 要获取日志文件，请在相关选项卡中点击 **STOP** 停止测量，然后点击 **SAVE** 将日志文件保存到 **[Beanviser-installation-path]/logs** 目录中。日志文件名会标明时间戳和日志类型。

从 Beanviser v1.5 起，比较结果仅显示数据的变化趋势。

### 提供汇总概览

提供其所收集全部信息的汇总视图。你可以将这些信息导出为 PDF 文件保存到本地系统。该信息位于 **Overview** 选项卡中，并在测量处于活动状态时实时更新。
