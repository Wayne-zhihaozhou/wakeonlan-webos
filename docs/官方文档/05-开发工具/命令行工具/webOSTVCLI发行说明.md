# CLI 发行说明
> 原文链接: https://webostv.developer.lge.com/develop/tools/webos-tv-cli-release-notes ｜ 简体中文翻译

注意：webOS TV CLI 已弃用

我们决定自 2024 年 3 月起不再支持 webOS TV CLI。我们建议您改用

[webOS CLI](webOSCLI简介.md)

。

webOS TV SDK 为 Web 应用开发提供了一系列工具，包括[命令行界面](webOSCLI简介.md)。借助该 SDK，您可以创建、调试、打包和测试 webOS TV 应用。

webOS TV CLI v1.12.4（2023 年 2 月）

修复缺陷

修复了在安装了最新版本（v2.0.6）Developer Mode 应用的 webOS TV 上尝试执行 `ares-install`命令时发生错误的问题。
