### [appinfo.json](配置文件/appinfo.json应用元数据.md)

该文件包含用于识别应用的应用元数据，以及安装和运行应用所需的其他信息。

webOS 事件允许 web 应用在特定情形下注册不同的事件处理程序。

Luna Service API 由 webOS TV 所需的基本服务和功能组成。

适用于 Node.js 的 webos-service 模块提供与系统总线的接口，并以熟悉的 Node.js 惯用方式封装。
