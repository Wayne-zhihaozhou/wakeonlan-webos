# 构建您的第一个 webOS TV 应用
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/build-your-first-web-app ｜ 简体中文翻译

webOS TV 的 Web 应用基本上与标准 Web 应用非常相似。此外，它们还可以访问通常为原生应用提供的硬件和操作系统功能。因此，如果您有构建 Web 应用的经验，就可以凭借您在 HTML、CSS 和 JavaScript 等基于标准的 Web 技术方面的知识，轻松开始为 webOS TV 开发 Web 应用。有关在开发 webOS TV Web 应用时使用标准 Web API 的信息，请参见 [Supported web API](../04-平台规格/Web平台/WebAPI与Web引擎.md#supported-web-api)。

下面介绍如何构建您的第一个 webOS TV 应用。您可以根据自己的偏好，使用 [webOS CLI](../05-开发工具/命令行工具/webOSCLI简介.md) 或 [webOS Studio](../05-开发工具/webOS%20Studio/webOSStudio简介.md) 来完成。

提示

在使用 webOS CLI 的每个步骤中，系统都会引导您输入应用或设备信息。如果您输入这些信息，下面的命令语法将会为您定制。这是可选的，但我们建议您提供这些信息。与使用默认值相比，它将帮助您更好地理解语法。

## 创建应用

webOS CLI

webOS Studio

输入您的应用信息。

1. 下载并安装 [webOS CLI](../05-开发工具/命令行工具/webOSCLI安装.md) 。
2. 使用 [ares-generate](../05-开发工具/命令行工具/webOSCLI开发者指南.md#ares-generate) 命令创建一个新应用。在本示例中，您将使用名为 [basic](应用模板.md#basic-web-app) 的模板来生成一个新应用。 `ares-generate -t basic ./sampleApp`
3. 输入 `app id` 、 `title` 和 `version` 。 `? app id com.domain.app ? title new app ? version 0.0.1` 如果应用生成成功，您将看到 `Success` 。 `Generating basic in ./sampleApp Success`
4. 检查是否已创建 `sampleApp` 目录。

现在您已经创建了第一个 Web 应用！您可以尝试[在模拟器上运行该应用](#launch-the-app-on-the-simulator)，或者，如果您有真实的 TV 设备并想在其上测试该应用，可以在[打包并安装应用之后于设备上运行它](#package-install-and-launch-the-app)。

## 在模拟器上启动应用

webOS CLI

webOS Studio

选择您要使用的模拟器版本。

1. 下载并安装 [webOS TV Simulator](../05-开发工具/模拟器与仿真器/Simulator安装.md) 。
2. 使用 [area-launch](../05-开发工具/命令行工具/webOSCLI开发者指南.md#ares-launch) 命令在模拟器上启动您的应用。 `ares-launch -s 24 ./sampleApp`

如果应用成功启动，您将在模拟器上看到 **Hello, World!**。

## 在 TV 设备上打包、安装和启动应用

要在 TV 设备上测试应用，您首先需要安装开发者模式应用，并将您的 PC 与 TV 设备连接。具体方法请参见 [Developer Mode App](开发者模式应用.md)。

webOS CLI

webOS Studio

输入您的设备信息。

使用 [ares-package](../05-开发工具/命令行工具/webOSCLI开发者指南.md#ares-package) 命令打包 `sampleApp` 目录中的应用。<br>您可以使用 `-o` 选项指定创建包文件的目录。`ares-package ./sampleApp`如果打包成功，您可以在**当前工作**目录中看到创建的包（`.ipk`）文件。使用 [ares-install](../05-开发工具/命令行工具/webOSCLI开发者指南.md#ares-install) 命令将包文件安装到 TV 设备。请务必正确输入包的文件名。<br>如果您在上一步中使用 `-o` 选项指定了保存包文件的目录，则还需要指定该路径。`ares-install -d myTV com.domain.app_0.0.1_all.ipk`使用 [area-launch](../05-开发工具/命令行工具/webOSCLI开发者指南.md#ares-launch) 命令在 TV 设备上启动应用。`ares-launch -d myTV com.domain.app`

如果应用成功启动，您将在 TV 设备上看到 **Hello, World!**。
