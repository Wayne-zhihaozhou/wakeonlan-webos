# 使用开发者模式应用测试应用
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/developer-mode-app ｜ 简体中文翻译

完成应用开发后，您可能需要测试应用。开发者模式应用提供了一种在 TV 上安装、调试和测试 webOS TV 应用的更快方式。下面介绍连接 TV 与 PC 的开发者模式应用背后的概念。

![在 webOS TV 上与笔记本电脑连接的开发者模式应用](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914917/webOS-TV/images/docs/guides/Overview_of_Dev_Mode_App_anmjzl.png)

要使用开发者模式应用，需要提前准备好以下内容：

- 连接到网络的 webOS TV
- 连接到与 webOS TV 相同网络并已安装[webOS CLI](../05-开发工具/命令行工具/webOSCLI简介.md)的 PC
- LG Developer 网站账号开发者模式应用要求您登录 LG Developer 网站。如果您还没有账号，请点击本页右上角的**SIGN IN**并先创建一个账号。

## 安装开发者模式应用

要安装开发者模式应用，请按以下步骤操作：

**Step 1:**首先，打开您的 webOS TV，并检查您的 webOS TV 是否已连接到网络。

**Step 2:**使用您的 LG Developer 网站账号登录。

**Step 3:**前往[LG Apps](https://www.lgappstv.com)。

**Step 4:**搜索 "Developer Mode."

**Step 5:**选择开发者模式应用，然后点击**Install**按钮。

## 开启开发者模式

安装开发者模式应用后，您可以在 TV 上启用开发者模式。

**Step 1:**从 webOS TV Launcher 运行开发者模式应用。

**Step 2:**输入 LG Developer 网站的**您的邮箱账号 ID**和**密码**。如果您还没有账号，请先创建一个账号。

![开发者模式应用的登录截图](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914917/webOS-TV/images/docs/guides/Login_of_Dev_Mode_App_l87hq9.png)

**Step 3:**点击**Dev Mode Status**按钮以启用开发者模式。TV 将重新启动。

![开发者模式应用的截图](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914915/webOS-TV/images/docs/guides/Dev_Mode_Status_On_qqzjd4.png)

注意：开发者模式为什么会禁用？

开发者模式会在以下情况下禁用：

- TV 在未连接到网络的状态下重启十次后。
- 当剩余会话时间用尽时，TV 重启后。

开发者模式被禁用后，您在开发者模式下使用的已安装应用将被卸载，并且您将被带到开发者模式应用的登录界面。

## 连接 TV 和 PC

本节介绍如何连接 webOS TV 和您的 PC。对于开发者模式应用，您可以使用[CLI](开发者模式应用.md#connecting-with-cli)或[webOS Studio](开发者模式应用.md#connecting-with-webos-studio)。

### 使用 CLI 连接

请按照以下说明使用 CLI 添加目标 TV：

**Step 1:**运行 **webOS CLI**。

**Step 2:**执行 **ares-setup-device** 命令。然后选择 **add**。

```shell
ares-setup-device

name     deviceinfo               connection profile
-------- ------------------------ ---------- -------
emulator developer@127.0.0.1:6622 ssh        tv

** You can modify the device info in the above list, or add new device.
? Select: (Use arrow keys)
> add
modify
remove
```

**Step 3:**按以下示例输入有关您的 TV 的信息：

注意：密码设置

您无需输入密码。使用开发者模式应用时不需要密码。

```shell
** You can modify the device info in the above list, or add new device.
? Select: add  
? Enter Device Name: tv2  
? Enter Device IP address: 10.123.45.67  
? Enter Device Port: 9922  
? Enter ssh user: prisoner  
? Enter description: new device
? Set default? Yes  
? Save ? Yes  
name deviceinfo connection profile
-------- -------------------------- ---- --
tv2 (default)  prisoner@10.123.45.67:9922  ssh         tv
emulator       developer@127.0.0.1:6622    ssh         tv
myTV           prisoner@192.168.0.22:9922  ssh         tv
```

**Step 4:**将您的 TV 添加为目标设备后，使用以下命令检查结果：

```shell
ares-setup-device --list
```

**Step 5:**在开发者模式应用中点击**Key Server**按钮。

![开发者模式应用上的 Key Server 按钮](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914918/webOS-TV/images/docs/guides/Key_Server_On_ql4tls.png)

**Step 6:**在您的 PC 上使用以下命令从 webOS TV 获取**密钥文件**：

```shell
ares-novacom --device tv2 --getkey
```

**Step 7:**将出现命令提示符，要求输入 **Passphrase**。请输入 TV 屏幕上显示的完全一致的字符（区分大小写）。您可以在开发者模式应用屏幕的左下角看到由 6 个字符组成的 Passphrase。

```shell
input passphrase:
```

**Step 8:**使用以下命令检查您的 TV 与 PC 之间的连接：

```shell
ares-device --system-info --device tv2
```

如果连接建立成功，将显示如下设备信息。该信息可能因您的 TV 设备而有所不同。

```shell
modelName : WEBOS6.0
 sdkVersion : 6.1.0
 firmwareVersion : 00.00.00
 boardType : K7LP_ATSC_KR
 otaId : HE_DTV_W21P_AFADATAA
```

**Step 9:**现在，您已准备好在真实 TV 上安装并启动您的应用。要了解具体方法，请参见[Install the web app](../05-开发工具/命令行工具/webOSCLI开发者指南.md#install-the-web-app)和[Launch the web app](../05-开发工具/命令行工具/webOSCLI开发者指南.md#launch-the-web-app)。

### 使用 webOS Studio 连接

请按照以下说明使用 webOS Studio 将您的 TV 添加为目标设备：

**Step 1:**运行 **VS Code**，并打开已安装的[webOS Studio](../05-开发工具/webOS%20Studio/webOSStudio安装.md)。

**Step 2:**从命令面板（*Ctrl+Shift+P*）中选择 **webOS: Set Up Device**，然后选择 **Add Device**。您也可以点击 **Known Device** 视图中的 **+** 按钮。

**Step 3:**输入用于连接的设备名称、IP 地址、端口号和用户名。端口号输入 **9922**，用户名输入 **prisoner**。

**Step 4:**在您的 TV 设备上开启开发者模式后，启动开发者模式应用。

**Step 5:**在开发者模式应用中点击**Key Server**按钮。

**Step 6:**从 VS Code 上的命令面板（*Ctrl+Shift+P*）中选择 **webOS TV: Set Up SSH Key**，然后选择您的设备。

**Step 7:**输入开发者模式应用中显示的 Passphrase（区分大小写）。

**Step 8:**刷新 **KNOWN DEVICE** 列表。

## 延长开发者模式时间

开发者模式仅在有限时间内可用。当您开启开发者模式时，可以在 Remain Session 字段中查看剩余会话时间。

要延长剩余时间，请将 TV 连接到网络，然后点击 **EXTEND** 按钮。如果会话时间已用尽，您将无法延长会话时间。

![开发者模式应用上的 Extend 按钮](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914915/webOS-TV/images/docs/guides/Extend_Dev_Mode_Time_zy6j3d.png)

## 清除应用缓存数据

开发者模式应用提供 **Clear Cache Data** 功能用于测试。请注意，所有应用的缓存数据都将被移除。

要清除所有应用的缓存数据，请按以下说明操作：

**Step 1:**点击 **Clear Cache Data** 字段上的 **ON** 按钮。

![开发者模式应用上的 Clear Cache Data 按钮](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914916/webOS-TV/images/docs/guides/Clear_Cache_Data_On_Dev_Mode_gdbnqf.png)

**Step 2:**重新启动 TV。
