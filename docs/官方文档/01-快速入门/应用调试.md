# 应用调试
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/app-debugging ｜ 简体中文翻译

您可以借助 Web Inspector 和 Node Inspector 监控在目标设备上运行的 Web 应用或 JS 服务的执行信息。为此，您需要创建一个未经过压缩（minify）处理的打包文件（.ipk）。

## Web Inspector

webOS TV 平台支持使用 Web Inspector 调试 Web 应用。Web Inspector 可以结合执行信息监控您的应用在目标设备上的运行情况。Web Inspector 默认使用 Chromium 浏览器。

要使用 Web Inspector，您需要安装 Chromium，且其版本需与 webOS TV 版本兼容。下表列出了各 webOS TV 版本所兼容的 Chromium 版本及其下载链接。
