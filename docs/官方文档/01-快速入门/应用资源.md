# 应用资源
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/app-resources ｜ 简体中文翻译

下表列出了一些常见的应用资源，并说明了在 webOS TV 应用中应将它们放置在何处。不要依赖 TV 设备的互联网连接来支撑应用的核心功能，并应将频繁访问的资源保留在应用本地——换句话说，将它们与应用一起打包，而不是每次需要时都通过互联网加载。

| **资源类型** | **推荐位置** | **注意事项（Do's and Don'ts）** |
| --- | --- | --- |
| 图片 | 随打包应用一起包含 | 请使用图片压缩工具来减小体积并缩短加载时间。 |
| 音频 | 通常随打包应用一起包含。如果体积较大且访问频率低，可以放在线上。 | 请选择能产生可接受音质的比特率。 |
| 视频 | 远程。如果体积较小或是应用功能所必需，视频资源可以随打包应用一起包含。即便如此，也应在需要时才加载它们。 | 请对视频资源进行预处理，使其具有应用所需的分辨率和比特率。 |
| 字体 | 随打包应用一起包含 | 请确保字体已获得适当的发布许可。 |
| 文本 | 随打包应用一起包含 | 请将少量文本直接写入应用源代码中。<br>如有需要，请通过本地 Ajax 请求加载较大的文件。 |

注意

每个资源的路径都应相对于 *index.html* 文件来指定。例如，它应当形如 `assets/my_image.png`，而不是以 `/media/developer/` 开头。后者在开发者模式应用中可能有效，但当应用通过 LG Seller Lounge 发布时就会失效。您也可以使用 webOSTV.js 库的 `webOS.fetchAppRootPath()` 方法。详情请参阅 [fetchAppRootPath](../03-API参考/webOSTV.js库/webOSTV.js的webOSAPI.md#fetchapprootpath)。

## 图标、背景与描述

要在 webOS TV 上运行您的应用，您必须在应用中包含下列资源。这些资源可确保您的应用在设计层面获得正确的品牌呈现，同时与系统 UI 及其他第三方应用保持一致。

### 应用图标

将应用图标文件放入应用中，并在 [appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md) 文件中指定名称。

| 资源 | 说明 |
| --- | --- |
| 小应用图标 | • 必需<br>• 规格：80 x 80 px，PNG<br>• appinfo.json 中的属性名：[icon](../03-API参考/配置文件/appinfo.json应用元数据.md#icon)<br>• 显示在系统通知中<br>• 在 webOS TV 1.0 上，该图标以 100 x 100 px 显示。 |
| 大应用图标 | • 必需<br>• 规格：130 x 130 px，PNG<br>• appinfo.json 中的属性名：[largeIcon](../03-API参考/配置文件/appinfo.json应用元数据.md#largeicon)<br>• 当用户在启动器（Launcher）上悬停于某个应用磁贴时，显示在屏幕左上角<br>• 在 webOS TV 2.0 上，该大图标以 115 x 115 px 显示。 |

这些图标文件是应用提交所必需的，但仅用于[应用测试](开发者模式应用.md)。在 [LG Apps](https://www.lgappstv.com/) 中，会改用您在 [LG Seller Lounge](http://seller.lgappstv.com/) 单独上传的 400x400 像素图标文件，经自动调整尺寸后使用。

以下是应用图标的设计指南。

- 建议小应用图标与大应用图标除尺寸外完全相同。这样用户更容易识别该应用。
- 小应用图标与大应用图标的[应用颜色](应用资源.md#app-color)应保持一致。它们都会始终显示在应用磁贴上。

![App tile color and padding guide](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914920/webOS-TV/images/docs/guides/Develop_webOSTV50_KeyAppAsset_AppIcon_sxgbpz.png)

### 背景图片

将背景图片文件放入应用中，并在 [appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md) 文件中指定名称。

| 资源 | 说明 |
| --- | --- |
| 启动画面背景图片 | • 必需<br>• 规格：1920 x 1080 px，PNG<br>• appinfo.json 中的属性名：[splashBackground](../03-API参考/配置文件/appinfo.json应用元数据.md#splashbackground)<br>• 在应用加载过程中显示在屏幕上 |

从 webOS TV 2015 机型开始，启动器背景图片和启动画面背景图片不再支持 PVR 格式。如果您已经向 [LG Seller Lounge](http://seller.lgappstv.com/) 提交了使用 PVR 格式图片的应用，则需要使用 PNG 格式图片重新打包应用并重新提交。

以下是应用启动画面的设计指南。

- 它不应是黑屏。
- 请尽可能少用文字，以避免本地化问题。

![Good and bad examples of the app splash image](https://res.cloudinary.com/dcsdn4mzr/image/upload/v1649914917/webOS-TV/images/docs/guides/Develop_webOSTV50_KeyAppAsset_Splash_vadhf5.png)

### 应用颜色

应用颜色是主屏幕上显示的应用磁贴的背景颜色。请在 [appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md) 文件中指定应用磁贴颜色。

| 资源 | 说明 |
| --- | --- |
| 应用磁贴颜色 | • 必需<br>• 规格：HEX VALUE<br>• appinfo.json 中的属性名：iconColor<br>• 应用磁贴的背景颜色。应用磁贴显示在主屏幕上。 |

### 应用描述

应用名称、应用次要描述和视图标题都是应用可用的描述项。请在 [appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md) 文件中指定它们。

| 资源 | 说明 |
| --- | --- |
| 应用名称 | • 必需<br>• 规格：<= 20 个字符<br>• appinfo.json 中的属性名：[title](../03-API参考/配置文件/appinfo.json应用元数据.md#title)<br>• 显示在系统通知中<br>• 当用户在启动器（Launcher）上悬停于某个应用磁贴时，显示在屏幕左上角、应用图标的右侧 |
| 应用次要描述 | • 可选<br>• 规格：<= 60 个字符<br>• appinfo.json 中的属性名：[appDescription](../03-API参考/配置文件/appinfo.json应用元数据.md#appdescription)<br>• 当用户在启动器（Launcher）上悬停于某个应用磁贴时，显示在屏幕左上角、应用名称的下方 |
| 视图标题 | • 规格：<= 60 个字符<br>• 视图标题由应用动态提供，没有对应的 appinfo.json 属性。如果应用未提供视图标题，该处留空。<br>• 显示在主屏幕左上角 |

#### 应用次要描述与视图标题

- 应用描述提供关于应用的简要信息；可以把它看作应用的宣传语。例如，Netflix 的应用描述可以是 *Watch millions of movies and TV shows anytime, anywhere*。
- 视图标题提供关于用户当前操作或应用当前屏幕内容的信息。例如，Netflix 的视图标题可以是观看者当前正在观看的电影名称（例如 *Kung-fu Panda 2*）。
- 应用描述与视图标题绝不应相同。

## 字体

webOS TV 不限制应用只能使用系统字体。您可以在应用中使用任何字体，不过我们推荐使用 WOFF 和 TTF。使用字体时请注意，您需对任何许可与分发要求承担全部责任。

您也可以将字体资源与应用一起打包。字体的引用路径相对于 *index.html* 文件所在位置。

以下示例为 h2 标签指定了字体资源：

```css
@font-face {
    font-family: AlexBrush;
    src: url('assets/AlexBrush-regular.ttf');
}
h2 {
    font-family: AlexBrush;
}
```

## 打包资源

您应当将资源与应用一起打包，以便部署到 webOS TV。

- 对于 Enyo 项目，请将资源放在 assets 目录中。自 webOS TV 4.5 起，我们不再支持 Enyo 框架。有关 Enyo 支持的更多信息，请参阅 [Enyo/Enact 指南](../02-开发指南/应用基础/Enyo与Enact指南.md)。
- 对于其他项目，请在应用中选择一个目录并将资源放在那里。您可以根据需要创建子目录来对资源进行分组。

### 访问图片、音频和视频资源

在包结构中，您可以相对于 *index.html* 文件所在位置来访问图片、音频和视频资源，CSS 资源除外。CSS 资源是相对于 CSS 文件所在位置引用的。

从 *index.html* 文件中，按如下方式引用 assets 目录中的图片：

```html
<body style='background-image: url("assets/my_image.png")'>
```

无论 JavaScript 文件位于项目中的何处，都适用相同的路径。

```javascript
myImage.setSrc("assets/my_image.png");
```

从位于 source/css 的 CSS 文件中：

```css
.my-background {
    background-image: url("../../assets/my_image.png");
}
```
