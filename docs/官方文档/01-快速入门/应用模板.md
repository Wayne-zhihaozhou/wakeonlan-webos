# 应用模板
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/app-template ｜ 简体中文翻译

为了帮助加速应用开发，webOS TV 平台为 Web 应用（包括基础（打包）Web 应用和托管 Web 应用）以及 JS 服务提供了模板。此外，还提供了 info 文件的模板。

## 可用模板列表

webOS TV 平台提供了若干模板。

| 类别 | 模板名称 | 描述 |
| --- | --- | --- |
| Web 应用 | basic | 基础 Web 应用的模板（默认） |
|  | hosted_webapp | 托管 Web 应用的模板 |
|  | webappinfo | 带有示例值的<br>*appinfo.json*<br>文件的模板 |
| JS 服务 | js_service | JavaScript (JS) 服务的模板 |
|  | jsserviceinfo | 带有示例值的<br>*package.json*<br>和<br>*services.json*<br>文件的模板 |
|  | pakageinfo | 带有示例值的<br>*packageinfo.json*<br>文件的模板 |

## Web 应用

### 基础 Web 应用

基础 Web 模板提供了一个 "Hello World" 应用，其中包含 webOS TV 所需的最少必要文件。当您使用其他 UI 框架时，该模板很有用。

下表描述了使用该模板创建的基础 Web 应用的目录/文件。

| 目录 / 文件 | 描述 |
| --- | --- |
| webOSTVjs-x.x.x | webOS TV 库目录。用于调用<br>[LS API](../03-API参考/webos-service与Luna/LunaServiceAPI简介.md)<br>的 webOS TV 专用库。有关 webOS TV 库的详细说明，请参见<br>[webOSTV.js](../03-API参考/webOSTV.js库/webOSTV.js库简介.md)<br>。 |
| appinfo.json | Web 应用配置文件。该<br>*appinfo.json*<br>文件包含 Web 应用的元数据。打包 Web 应用时此文件必须存在。有关<br>*appinfo.json*<br>文件的详细说明，请参见<br>[appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md)<br>。 |
| icon.png | 图标图像文件。有关<br>*icon.png*<br>文件的详细说明，请参见<br>[App icons](应用资源.md#app-icons)<br>。 |
| largeicon.png | 大图标图像文件。有关<br>*largeicon.png*<br>文件的详细说明，请参见<br>[App icons](应用资源.md#app-icons)<br>。 |
| index.html | Web 应用的主页面。此页面仅在屏幕上显示 "Hello World" 文本。 |

### 托管 Web 应用

托管 Web 应用模板提供了一个托管 Web 应用，其中包含一个重定向 URL 以及 webOS TV 所需的最少必要文件。

下表描述了使用该模板创建的托管 Web 应用的目录/文件。

| 目录 / 文件 | 描述 |
| --- | --- |
| appinfo.json | Web 应用配置文件。appinfo.json 文件包含 Web 应用的元数据。打包 Web 应用时此文件必须存在。有关<br>*appinfo.json*<br>文件的详细说明，请参见<br>[appinfo.json](../03-API参考/配置文件/appinfo.json应用元数据.md)<br>。 |
| icon.png | 图标图像文件。有关<br>*icon.png*<br>文件的详细说明，请参见<br>[App icons](应用资源.md#app-icons)<br>。 |
| largeicon.png | 大图标图像文件。有关<br>*largeicon.png*<br>文件的详细说明，请参见<br>[App icons](应用资源.md#app-icons)<br>。 |
| index.html | Web 应用的主页面，其中包含重定向 URL。 |

### Web 应用信息

Web 应用信息模板提供了一个带示例值的*appinfo.json*文件。如果您要在不使用模板的情况下构建新的 Web 应用，或者使用并非由模板创建的现有 Web 应用，则应将该*appinfo.json*文件添加到您的应用中。该*appinfo.json*文件保存应用名称、ID、应用类型、图标图像以及主页面信息。

webOS TV CLI 提供如下*appinfo.json*文件模板。

```shell
{
  "id": "com.domain.app",
  "version": "0.0.1",
  "vendor": "My Company",
  "type": "web",
  "main": "index.html",
  "title": "new app",
  "icon": "icon.png",
  "largeIcon": "largeIcon.png"
}
```

## JS 服务

### JS 服务

JS 服务模板提供了一个示例 JS 服务，它作为后台服务在 webOS TV 上运行。该示例 JS 服务会响应服务请求的简单消息。

下表是对使用该模板创建的 JS 服务的目录/文件的基本描述。

| 目录/文件 | 描述 |
| --- | --- |
| helloworld_service.js | 示例 JS 服务代码，提供若干简单命令。这些命令在 services.json 文件中指定后才能使用。 |
| package.json | NPM 的配置文件。有关更多信息，请参见<br>[npm Docs](https://docs.npmjs.com/getting-started/using-a-package.json)<br>。 |
| services.json | 该配置文件定义服务在 webOS 总线上提供哪些命令。有关更多信息，请参见<br>[services.json](../03-API参考/配置文件/services.json服务配置.md)<br>。 |

### JS 服务信息

JS 服务信息模板提供带示例值的*package.json*和*services.json*文件。如果您要在不使用模板的情况下创建 JS 服务，或者使用并非由模板创建的现有服务，则应将该 JS 服务信息模板中的*package.json*和*services.json*_ 文件添加到您的应用中。

使用此模板生成的*package.json*文件如下所示：

```shell
{
  "name": "com.domain.app.service",
  "version": "1.0.0",
  "description": "Helloworld service",
  "main": "helloworld_service.js",
  "scripts": {
    "test": "echo "Error: no test specified" && exit 1"
  },
  "author": "",
  "license": "BSD"
}
```

使用此模板生成的*services.json*文件如下所示：

```shell
{
  "id": "com.domain.app.service",
  "description": "HelloWorld Service",
  "services": [
    {
      "name": "com.domain.app.service"
    }
  ]
}
```

### 包信息

包信息模板用于生成*packageinfo.json*文件，该文件定义包的内容。一个包包含一个应用和零个或多个服务。

使用此模板生成的*packageinfo.json*文件如下所示：

```shell
{
  "id": "com.domain",
  "version": "0.0.1"
}
```
