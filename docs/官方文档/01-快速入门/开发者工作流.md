## 快速开始

### 安装基本工具

作为起点，请先安装基本工具：

[webOS CLI](../05-开发工具/命令行工具/webOSCLI安装.md)

、

[webOS Studio](../05-开发工具/webOS%20Studio/webOSStudio安装.md)

和

[Simulator](../05-开发工具/模拟器与仿真器/Simulator安装.md)

。您在为 webOS TV 开发应用时很可能需要它们。

- CLI 提供了一组用于创建和管理应用的命令，让您无需特定的 IDE 即可进行开发和测试。
- 如果您熟悉 VS Code，可以使用 webOS TV 的 VS Code 扩展在其中进行开发。
- Simulator 是一个更直观的工具，提供包括调试在内的应用开发环境。它可以在大多数 PC 上运行，无需额外的环境设置。

### 尝试构建第一个应用

在开始编写您自己的应用之前，我们建议您先通过最简单的形式熟悉 webOS TV 应用。请尝试

[构建您的第一个应用](构建第一个应用.md)

。

### 学习 webOS TV 应用的基础知识

了解一些关于 webOS TV 应用的基础知识，将帮助您理解这些应用的工作方式，并构思出属于您自己的应用。

- [Web 应用类型](Web应用类型.md)
- [应用模板](应用模板.md)
- [应用资源](应用资源.md)

## 开发

### 设计您的应用

现在来设计您的应用！

- 在设计应用之前，请先查看[平台规范](../04-平台规格/00-推荐阅读.md)，以提前消除因规范不匹配而导致的错误。
- 我们提供了一些 UI/UX 设计指南，例如 [Design Principles](https://webostv.developer.lge.com/develop/guides/design-principles) 和 Style Guidelines ，可供您参考。

### 实现应用

此阶段是您充分利用 webOS TV 来实现应用功能与特性的地方。

- 您可以使用 HTML、CSS 和 JavaScript 等关键 Web 技术为 webOS TV 开发 Web 应用。请查看[支持的标准 Web API](../04-平台规格/Web平台/WebAPI与Web引擎.md#supported-web-api) 。
- 按您想要添加的功能/特性查找[开发者指南](../02-开发指南/00-推荐阅读.md)。
- [webOS TV 应用示例](../06-示例应用/示例应用清单.md)可在 GibHub 上获取。

### 测试和调试应用

测试您的应用是否按预期工作，并消除所有影响其可用性和性能的缺陷。

- 在 [Simulator](../05-开发工具/模拟器与仿真器/Simulator简介.md) 上检查您的应用如何运行。或者，要在真实 TV 上测试应用，请使用[开发者模式应用](开发者模式应用.md) 。
- 在 CLI 上，您可以使用 ares-device-info 快速检查资源使用情况。要进行深入分析，请使用 Resource Monitor 实时监控和分析您的应用及 webOS 系统的资源使用情况。请参见 [Resource Monitor](../05-开发工具/性能分析工具/资源监视器简介.md) 。
- 使用 [Web Inspector](应用调试.md#web-inspector) 结合执行信息监控您的应用，或使用 [Node Inspector](应用调试.md#node-inspector) 调试所使用的 JS 服务。

## 分发

### 使用检查清单检查应用

在提交应用之前，您需要使用提供的自查清单检查应用，以加快提交流程。

- [自查清单](https://webostv.developer.lge.com/distribute/app-self-checklist)列出了 LG 应用质量保证团队使用的标准，因此您可以预先检查应用的质量。

### 提交并分发应用

将您的应用提交至

[LG Seller Lounge](http://seller.lgappstv.com/)

。一旦验证适合发布，应用将发布到

[LG Apps](https://www.lgappstv.com/)

。
