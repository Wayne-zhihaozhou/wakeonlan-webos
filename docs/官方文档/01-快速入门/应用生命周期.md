# 应用生命周期
> 原文链接: https://webostv.developer.lge.com/develop/getting-started/app-lifecycle ｜ 简体中文翻译

了解 webOS TV 应用的生命周期，有助于您在开始设计应用之前对其工作方式形成一个大致轮廓。本节将基于应用可能处于的状态以及状态之间的转换来介绍应用生命周期。

## 应用的状态

webOS TV 应用可能处于的状态包括：未启动、已启动（前台）、已挂起（后台）。应用的状态可以且将会因用户交互或系统事件而发生改变。

![App lifecycle](https://res.cloudinary.com/dcsdn4mzr/image/upload/f_auto/q_auto/v1699323369/webOS-TV/images/docs/guides/webOS_TV_App_Lifecycle_tpmo5y.jpg)

- **未启动（Not Launched）**：应用尚未启动，或者已被终止。在此状态下，如果应用接收到 `**webOSLaunch`** 事件或 **`visibilityChange`** 事件（可见），它将会被启动。已启动或已挂起的应用可以通过以下方式被终止并回到未启动状态：用户在应用 UI 上退出它、使用 **`ares-launch --close`** 命令，或者在模拟器上点击菜单中的 **Close App** 或 RCU 上的 **Close**。
- **已启动（Launched）**：应用正在前台运行。已启动的应用随时可能被终止或挂起。在此状态下，如果用户启动另一个应用，该应用将接收到 **`visibilityChange`** 事件（隐藏）并变为挂起且隐藏。
- **已挂起（Suspended）**：应用在后台挂起。应用可以短暂挂起以执行特定的后台任务。在此状态下，如果应用接收到 **`webOSRelaunch`** 或 **`visibilityChange`** 事件（可见），它将被恢复为已启动状态。
